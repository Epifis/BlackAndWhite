# Proyecto BlackAndWhite

Este proyecto implementa una simulación del juego BlackAndWhite con una interfaz gráfica y una estructura de búsqueda de estados. El juego consiste en manipular una serie de casillas con valores de "B" (negro), "W" (blanco), y "-" (vacío), donde se deben aplicar una serie de acciones para cambiar su estado.

## Descripción

El proyecto consta de tres componentes principales:
- **Clases de Lógica**: Implementadas en Java, gestionan el estado del juego, las acciones posibles y las transiciones de estado.
- **Controlador**: Orquesta la lógica y permite la integración con la interfaz de usuario.
- **Interfaz Gráfica de Usuario (GUI)**: Proporciona una vista para interactuar con el juego.

## Tecnologías utilizadas

- **Java**: Lenguaje principal utilizado para el desarrollo.
- **Swing**: Usado para la creación de la interfaz gráfica.
- **Javadoc**: Generación de documentación técnica.

## Requisitos

- **Java 8** o superior.
- Un entorno de desarrollo como **NetBeans**, **Eclipse**, o cualquier IDE compatible con Java.
